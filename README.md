# LULUWA KEYF — Next.js

Luluwa Keyf için hazırlanmış tek sayfalık, responsive restoran/cafe web sitesi.

## İçerik
- LULUWA KEYF logo ve hero alanı
- 9 gerçek kafe / üst kat fotoğrafı
- 24 adet menü sayfasının tamamı
- Menü sayfalarında tam ekran lightbox + önceki/sonraki gezinme
- Eşit ölçülü responsive fotoğraf kartları
- Mobil menü, telefon/rezervasyon CTA'ları
- Scroll progress ve CSS tabanlı reveal animasyonları
- Framer Motion bağımlılığı kaldırıldı; `activeAnimations` / `motion-dom` build hatası bu nedenle projede kullanılmıyor

## Çalıştırma
```bash
npm install
npm run dev
```

Ardından `http://localhost:3000` adresini aç.
